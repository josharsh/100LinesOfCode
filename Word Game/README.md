# Word Game

## Description
There are 3 levels in this game, easy to hard. Your task is to solve the missing letter. Each level will have shorter words than the previous. You need to get 5 out of 5 letters correct to move onto the next level or else the game ends. You will have 3 lives to play with. 

## Installation
You will need Python installed. You will need to install random and os to import(the imports are done by the script).

## Usage
The file can run on your IDE by clicking "Run"
