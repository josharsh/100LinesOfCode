# Snake Game
A simple snake game written in C++<br>

## Installation
Make sure you have C++ installed on your system
<br>
```clang++ -O2 -std=c++17 main.cpp -o main.exe```
<br> or<br>
```g++ -g main.cpp -o main.exe```

Execute the following to play <br>
```./main.exe```

## Keybindings
* ```W``` + ```Enter```  = Up
* ```A``` + ```Enter```  = Left
* ```S``` + ```Enter```  = Down
* ```D``` + ```Enter```  = Down
* ```Q``` + ```Enter```  = Quit
