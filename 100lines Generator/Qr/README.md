# QR Code Generator

Generate a QR code from any text or URL and save it as a PNG image in the
user's `Downloads` folder.

## Setup

```bash
python3 -m pip install -r requirements.txt
```

## Usage

```bash
python3 qr_generator.py
```

Enter the data when prompted. The generated `qr_code_*.png` file can be opened
or shared like any other photo.
