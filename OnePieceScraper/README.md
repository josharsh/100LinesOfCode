# One Piece Scraper

This python script can be used to scrape all one piece episodes using the CLI

## Technology

Python3 is needed to run the script

### Usage

#### Installing python3

Install python3 using the following [download](https://www.python.org/downloads/)

#### Installing Required Packages

* Once python is installed, install pip using the steps in this [website](https://pip.pypa.io/en/stable/installing/)
* Install requests module using pip

```bash
pip install requests
```

* Install BeautifulSoup using pip

```bash
pip install beautifulsoup4
```

* Installing TQDM

```bash
pip install tqdm
```

#### Running the script

Simply run the script using python

```bash
python ./one_piece_scraper.py
```
