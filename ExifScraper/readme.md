# EXIF data scraper

## Description
Gets image metadata like camera, camera model, data and time, orientation, size

## Requirments
```bash
Python 3.13.5 or higher
```

```bash
pip install Pillow
```

## Usage
python main.py <path_to_image>

## Technologies
- Python
- Pillow
